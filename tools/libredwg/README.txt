dwg2dxf.exe
===========
GNU LibreDWG, development version 46c4459 (newer than release 0.13.3,
which could not read some recent AutoCAD files), compiled for Windows 64-bit as one
self-contained program (no DLLs needed). Source: https://github.com/LibreDWG/libredwg
(commit 46c44598d2e321a06ba3348d868772e6ccadea0f), unmodified.
Used by tools\cad_inspect.py and tools\build_layout3d.py to convert DWG to DXF without AutoCAD.
